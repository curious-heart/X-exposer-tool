# X-exposer 开发指引

## 项目背景

- X-exposer 是 Windows 上的 X 射线发生器自动测试工具。项目中称设备为 DR。
- 操作员连接设备并设置参数后，软件按测试方案下发曝光参数、发起曝光、回读反馈、判断是否在设定范围内，并生成结果。
- 项目使用 Qt 5.15.2 Widgets、qmake 和 C++17。开发入口是 Qt Creator 中的 `X-exposer.pro`，现有 Windows kit 为 MSVC2019 64 位。

## 多设备要求

- 一台电脑运行一个 X-exposer 进程，同时测试至少 8 台 DR。每台 DR 使用独立 COM 口或独立的网络地址与端口。现场允许不同 DR 的曝光时间重叠。
- 每台 DR 的连接、参数、测试进度、暂停、重连、判定和 CSV 结果各自管理。暂停、停止或断开一台设备时，其余设备的测试任务继续。
- DR 没有停止曝光接口。软件停止测试后，已经启动的曝光由 DR 自然结束。
- 测试参数的单位关系见根目录 `README.md`。修改设备流程和报告时保留现有的单位换算、参数校验和判定规则。

## 代码入口

- `main.cpp` 和 `multi_dr_window.*` 管理应用入口、设备列表和批量操作。
- `main_dialog.*`、`hv_connsettings.*`、`test_param_settings.*` 管理单台设备的连接、参数、监控和报告。
- `hv_tester/` 实现曝光测试状态机，`test_result_judge/` 实现反馈判定。
- `configs/configs.ini` 是应用级配置。`.user_settings.ini` 保存本机设备及界面设置。

## 工作约定

- 功能代码在 `feature/*` 分支上开发。项目修改记录和开发说明放在 `01.proj-dev-docs/` 并由 Git 跟踪。
- 推送分支时，默认同时推送到 `x-exposer-tool` 和 `gkxg-x-exposer`，并分别核对结果。用户明确指定推送范围时，按当次指示执行。
- 优先用本机模拟设备验证多路连接和报告归属。连接实机进行曝光测试前，由现场人员安排并确认联调条件。
- 多设备改动至少检查单台流程、8 台独立端点并发、同型号报告隔离，以及一台设备暂停、停止或断线后其余任务的进度。
