# 多台 DR 独立测试

## 使用方式

1. 启动程序，在设备总览选择设备。首次使用多设备版本时，`DR-01` 读取旧版的连接和测试设置。
2. 点击「添加设备」，为新增设备填写唯一编号，在「高压连接设置」中配置独立 COM 口或网络地址与端口。设备列表和各台设备的配置保存在应用工作目录的 `.user_settings.ini`。
3. 为各台设备设置测试参数并连接。选中已连接且参数有效的设备，点击「开始所选测试」。也可以在右侧单台开始、暂停、恢复或停止。
4. 双击设备行或点击「打开详情与监控」，在该台设备的窗口查看原有参数和监控。关闭详情窗口后，测试继续在总览中运行。
5. 在总览选中已结束的设备，点击「打开最近报告」。每次运行单独写入一个 CSV，文件名包含设备编号和本次运行的唯一标识。
6. 在总览选中空闲设备，点击「删除设备」并确认。这会断开该台连接、删除其设置并保留已生成的 CSV。正在测试或暂停的设备需先停止。

## 修改记录

### 5.00 · 2026-11-24

- 新增设备总览，按设备显示连接状态、测试状态、曝光进度和最近结果。使用现有 Qt 事件循环并行推进测试任务。
- 复用原有单台界面和三种 Modbus 客户端。连接、曝光状态机、计时器、结果判定和 CSV 文件按设备实例管理。
- 保存连接设置时检查所有设备。相同的 IP 和端口组合或相同的 COM 号只能分配给一台 DR。更换站号或切换网络协议后，仍按同一网络端点检查。已有配置如有重复，需先修改其中一台的设置才能连接。
- 设备总览支持删除单台设备及其配置。删除后保存设备列表，包含所有设备均已删除的情况。
- 将冷却起点、剩余时间基准和参数范围校验器改为实例成员。Modbus 响应只在归属请求仍有效时更新测试或监控。
- 按设备隔离设置组。串口配置按端口名恢复，同时兼容旧版保存的索引。旧版单台配置仍由 `DR-01` 读取。
- CSV 保留现有记录结构，增加设备编号，并用独立文件保存同一时刻启动的测试。主动中止会结束并写入该台记录。
- 若停止时该台仍有 Modbus 请求等待回执，关闭该台连接以取消待重试请求。下一次测试前可重新连接。已经启动的曝光由 DR 自然结束。

## 实现范围

- 用于独立串口、独立 Modbus TCP 或独立 RTU over TCP 端点。目标支持至少 8 台设备，软件未设置固定台数上限。
- 曝光进度统计已经结束的计划参数组。判定重试计入当前组的尝试过程。
- 「最近报告」指本次软件运行期间该台最近结束的测试。历史文件可在应用工作目录的曝光测试结果文件夹中查看。

## 验证记录

- 使用 Windows x64、Qt 5.15.2 和 MSVC 14.29 完成 Release 构建。
- 使用 8 个本机 Modbus TCP 模拟端点同时运行，验证曝光时间重叠、设备参数各自下发、各台 CSV 路径及设备编号独立。
- 验证单台暂停后恢复、停止后重新运行、中途断线后重连、关闭详情窗口、重复连接端点拦截，以及单台反馈超限后重试并独立记录未通过。
- 验证离线设备的重复 IP 和端口、重复 COM 号会在保存时被拦截，同一 IP 使用不同端口可以通过校验。已有重复配置在连接时拦截。
- 验证取消删除、禁止删除正在测试的设备、删除后保留报告和其他设备的测试进度，以及清空设备列表后重启仍显示空列表。
- 实机、物理 COM 口和 RTU over TCP 仍需现场联调。
